# Reporte de influencers · Alimentos Polar

Reporte de la campaña UGC de Felipe Agency para Alimentos Polar (Atún P.A.N, Buena Mesa, Donkat y Aunt Jemima) en Instagram y TikTok. Lo prepara Datalítica.

Publicado en https://polar.datalitica.com.co (GitHub Pages, sin indexar en buscadores).

| Archivo | Qué es |
|---|---|
| `index.html` | El reporte: pestañas Resumen de campaña + una por marca, hallazgos y conversación. No se edita para actualizar cifras. |
| `datos/reporte.js` | Todos los datos: salidas, métricas por pieza y comentarios clasificados. Es lo único que cambia en una actualización. |
| `pdf/*.pdf` | Un PDF por pestaña. Los genera `scripts/render_pdf.py`. |
| `assets/` | Logos (Polar, Felipe Agency) y favicon. |
| `legal/` | Términos y política de datos de Datalítica. |

Cómo actualizar: ver `docs/RUNBOOK.md`.
